# Contributing

Thank you for helping improve DoveWAI Protocol.

## Principles

Contributions should keep the protocol small, vendor-neutral, transport-neutral, interoperable, and safe to implement independently of DoveWAI commercial services.

Before proposing a new core field, explain why it cannot be represented as an extension and how it interoperates with existing standards such as MCP, A2A, JSON Schema, and OpenTelemetry.

## Changes

For protocol changes, include:

1. Problem statement and interoperability use case.
2. Proposed schema/spec change.
3. Backward-compatibility impact.
4. Security/privacy impact.
5. At least one concrete example.
6. Tests or validation fixtures when code exists.

Breaking changes to published versions require explicit versioning discussion.

## Pull requests

Keep pull requests focused. Do not include credentials, private DoveWAI infrastructure details, customer data, proprietary datasets, or material copied from incompatible sources.
